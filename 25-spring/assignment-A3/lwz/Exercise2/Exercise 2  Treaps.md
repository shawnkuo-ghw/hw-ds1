### Exercise 2 : Treaps

#### Task 1 : Possible outputs of Treap generation

There are **5** different shapes of trees if the Treap is generated by inserting the sequence of elements [1, 2, 3] in that order.

Denote the priorities of 1, 2, 3 as p1, p2, p3. They are randomly chosen when inserting the corresponding key.

Here are the possible shapes of trees :

1. Totally right-skewed

   ```sql
   (1, p1)
      \
      (2, p2)
         \
         (3, p3)
   ```

   with priorities order : p1 < p2 < p3

2. Balanced

   ```sql
       (2, p2)
       /    \
   (1, p1)  (3, p3)
   ```

   with priorities order : P2 < p1, p3 

3. Totally left-skewed

   ```sql
       (3, p3)
       /
     (2, p2)
     /
   (1, p1)
   ```

   with priorities order : p3 < p2 < p1

4. Right-heavy but 3 promoted

   ```sql
   (1, p1)
      \
      (3, p3)
       /
     (2, p2)
   ```

   with priorities order : p1 < p3 < p2

5. Left-heavy but 1 promoted

   ```sql
      (3, p3)
      /
   (1, p1)
     \
     (2, p2)
   ```

   with priorities order : p3 < p1 < p2
