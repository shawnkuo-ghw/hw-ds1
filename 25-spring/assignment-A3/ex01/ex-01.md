- **Precondition :** Pre(a, l, r) : $0 \leq l\leq r < length(a)$.

    it ensures that the value of indexes l and r are within a valid range of the array a.

- **Postcondition : ** Post(a, l, r, i) : 

    1. Partitioning : 
        - For all k in [l, i - 1] : a[k] $\geq$ a[i];
        - For all k in [i + 1, r] : a[k] < a[i];
    
        We move i and j from right to left and set the first key of the original array as the pivot. After the execution, a[i] is the pivot and we set all the keys that are smaller than a[i] to the right and all the keys that are greater than or equal to a[i] to the left. Therefore this expression of partitioning is correct.
    
    2. Pivot preservation : 
    
        - a[i] == original(a[l]).
    
        original(a[l]) is the pivot. Since we swap a[i] and a[l] after the loop, then now a[i] is the pivot and it definitely equal to original a[l]. Therefore pivot preservation is correct.
